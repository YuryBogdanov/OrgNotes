# ТЗ: закрытие несохранённой вкладки

2026-10-10 · Yury Bogdanov

## Когда показывается диалог

Диалог нужен только тогда, когда закрытие может привести к потере несохранённых изменений. Несохранённая вкладка — это вкладка с точкой вместо крестика или вкладка «Без названия», в которой есть текст.

| Действие | Что закрывается | Диалог |
| --- | --- | --- |
| ⌘W, крестик или «Закрыть» в меню вкладки | Вкладка файла с несохранёнными изменениями | Вариант «файл» |
| То же | Вкладка «Без названия» с текстом | Вариант «пустая вкладка» |
| То же | Вкладка «Без названия» без текста, или вкладка без изменений | Не показывается, вкладка закрывается сразу |
| «Закрыть остальные», ⌥⌘W | Все вкладки панели, кроме текущей | Вариант «несколько вкладок», если среди них есть несохранённые |
| Закрытие панели кнопкой «Второй редактор» или командой | Вкладки панели переносятся в оставшуюся, ничего не закрывается | Не нужен |
| Закрытие окна (⌘⇧W, красный кружок) или выход (⌘Q) | Все вкладки обеих панелей | Вариант «несколько вкладок», если есть несохранённые; иначе не показывается |

Если один и тот же файл открыт в двух панелях («Продублировать в соседнем редакторе»), текст в них общий, и диалог при закрытии одной из вкладок не нужен: изменения никуда не делись. Диалог появляется, только когда закрывается последняя вкладка с этим файлом.

## Вид и тексты

Диалог — стандартный лист macOS, прикреплённый к заголовку окна, как и «Сохранить как»: ширина 440 pt, поверх окна — затемнение, над которым нельзя работать, пока лист открыт. Слева — иконка приложения 48 pt, рядом заголовок полужирным 13 pt и пояснение серым 12 pt. Кнопки внизу: «Не сохранять» слева, «Отмена» и основная синяя кнопка справа. Макеты в светлой и тёмной теме: раздел «Закрытие несохранённой вкладки» на дизайн-канве.

| Вариант | Заголовок | Пояснение | Главная кнопка |
| --- | --- | --- | --- |
| Файл | Сохранить изменения в «имя файла»? | Если не сохранить, изменения будут потеряны. | Сохранить |
| Новая заметка | Сохранить заметку «первая строка»? | Текст пока не записан в файл. Нажмите «Сохранить…», чтобы выбрать, куда его сохранить. | Сохранить… (с многоточием) |
| Несколько вкладок | Сохранить изменения в N вкладках? | Если не сохранить, изменения будут потеряны. Для новой заметки откроется «Сохранить как». | Сохранить всё |

**Детали вариантов:**

- В варианте «несколько вкладок» под пояснением список вкладок: иконка файла, имя, справа подпись «изменён» или «новая заметка» и оранжевая точка. Новая заметка написана курсивом. Если в списке больше шести строк, список прокручивается.
- Имя новой заметки в заголовке берётся из её первой непустой строки без звёздочек, обрезанной до 40 символов с многоточием. Такое же имя подставляется в поле «Сохранить как».
- Имена файлов везде без «.org» (см. ТЗ «доработки вкладок», правка 1).

## Кнопки и клавиши

По умолчанию выбрана главная кнопка (синяя): это безопасный вариант, при котором ничего не теряется. Tab переключает кнопки, Return нажимает выбранную. Пока лист открыт, остальное окно не реагирует, а повторный ⌘W ничего не делает.

| Кнопка | Клавиша | Что происходит |
| --- | --- | --- |
| Сохранить / Сохранить… / Сохранить всё | Return | Файл записывается на диск, затем вкладка закрывается. Для новой заметки открывается лист «Сохранить как», и вкладка закрывается после того, как файл создан. |
| Не сохранять | ⌘D | Вкладка (или все вкладки из списка) закрывается без записи, изменения теряются. |
| Отмена | Esc, ⌘. | Лист закрывается, всё остаётся как было: вкладки открыты, текст на месте. |

**Если что-то пошло не так:**

- Ошибка записи файла (нет прав, диск заполнен). Вкладка не закрывается, показывается стандартное сообщение об ошибке с причиной, текст остаётся в редакторе.
- Отмена в листе «Сохранить как». Закрытие отменяется целиком, вкладка остаётся открытой с текстом.
- «Сохранить всё» при нескольких вкладках. Вкладки обрабатываются слева направо, сначала левая панель, потом правая. Файлы пишутся сразу, для каждой новой заметки по очереди открывается «Сохранить как». Если на любом шаге нажата «Отмена» или возникла ошибка, закрытие останавливается: уже сохранённые вкладки остаются открытыми без точки, остальные — как были, ничего не закрывается.

## Особые случаи

- **Пустая заметка.** Вкладка «Без названия», в которой нет ничего, кроме пробелов и переводов строки, считается пустой и закрывается без диалога. Точка на такой вкладке не показывается, пока текста нет.
- **Закрыть остальные.** Текущая вкладка остаётся открытой, в списке диалога её нет, даже если в ней есть несохранённые изменения. Если у остальных нет изменений, они закрываются без диалога. Команда недоступна (серая), пока в панели одна вкладка.
- **Один файл в двух панелях.** Диалог показывается, только когда закрывается последняя вкладка этого файла. В списке нескольких вкладок такой файл показывается один раз, и в числе в заголовке учитывается один раз.
- **Вкладка агенды.** Диалог не нужен: сохранять там нечего. Вкладки агенд не попадают и в список диалога.
- **Выход из приложения (⌘Q) и закрытие окна.** Диалог один на всё окно и показывает несохранённые вкладки обеих панелей. После «Отмена» приложение остаётся работать.

Вне объёма этого ТЗ и будет описано отдельно: файл изменился на диске другой программой, пока в вкладке есть несохранённые изменения.

## Приёмка

Пройти по списку и прислать скриншоты каждого варианта диалога в светлой и тёмной теме.

- [ ] ⌘W на вкладке с изменениями: лист «Сохранить изменения в «имя»?»; «Сохранить» записывает файл и закрывает вкладку
- [ ] «Не сохранять» (⌘D) закрывает вкладку, файл на диске не меняется
- [ ] «Отмена» (Esc) возвращает в редактор, текст и положение курсора на месте
- [ ] Новая заметка с текстом: «Сохранить…» открывает «Сохранить как» с именем из первой строки; отмена в нём оставляет вкладку открытой
- [ ] Пустая вкладка «Без названия» без текста и вкладка без изменений закрываются без диалога
- [ ] «Закрыть остальные»: диалог показывает только остальные вкладки с изменениями, текущая в списке нет
- [ ] Тот же файл в двух панелях: диалог только при закрытии последней вкладки с ним
- [ ] ⌘Q и закрытие окна: один диалог со списком вкладок обеих панелей
- [ ] «Сохранить всё»: файлы пишутся сразу, для новых заметок по очереди «Сохранить как»; отмена или ошибка на любом шаге ничего не закрывает
- [ ] Ошибка записи файла: вкладка остаётся, показано сообщение об ошибке
- [ ] Пока лист открыт, повторный ⌘W и клики по окну ничего не делают
- [ ] Тёмная тема: лист, список и оранжевая точка читаются, контраст не хуже светлой

# ТЗ: выбор даты в календаре (палитра, ⇧ + стрелки)

2026-10-11 · Yury Bogdanov

## Контекст

Сейчас «Запланировать…» и «Поставить дедлайн…» в палитре предлагают «Сегодня», «Завтра», «Через неделю», «Убрать дату» и ввод даты текстом (`dateStep` в `commands.ts`). Добавляем четвёртый вариант — **«Выбрать дату…»**: календарь на три месяца, по которому ходят ⇧ + стрелки, как `org-read-date` в Emacs. Мышь не нужна. Поле ввода остаётся активным, так что текст и календарь работают вместе.

Макеты: группа «Палитра: выбор даты в календаре», светлая и тёмная темы.

- «Палитра — запланировать: варианты» — шаг с новым пунктом.
- «Палитра — запланировать: календарь (⇧ + стрелки)» — сам календарь.

Отдельный пикер «Выбор даты в тексте» (вставка даты в произвольное место текста) этим ТЗ не меняется.

## 1. Шаг вариантов

Как сейчас, плюс:

- **Метка в поле ввода** «Запланировать» (или «Дедлайн») с иконкой — как метка шага в ТЗ 16. Над полем плашка с заголовком задачи.
- **Новый пункт** между «Через неделю» и «Убрать дату»: иконка календаря, «Выбрать дату…», подсказка «календарь на 3 месяца», справа клавиша `⇧ + стрелки`. ↩ на нём открывает календарь.
- **⇧ + стрелка прямо на этом шаге** открывает календарь сразу со сдвигом: ⇧→ — календарь на завтрашней дате, ⇧↓ — на дате через неделю, и т. д. (от исходной даты, раздел 2).
- **Подвал:** «↑↓ выбрать · ⇧ + стрелки календарь · ↩ выполнить · ⎋ закрыть».

Обычные ↑↓ по-прежнему двигают выбор по строкам списка.

## 2. Календарь

**Размер.** Палитра расширяется с 640 до 800 pt, с плавной анимацией ширины ~150 мс. На узком окне ширина ограничена окном минус 32 pt, месяцы переносятся (раздел 5).

**Исходная дата** при открытии:

1. если у задачи уже есть дата этого типа — она;
2. иначе, если в поле что-то введено и это распознаётся как дата — она;
3. иначе сегодня.

Выбранная дата сразу подсвечена.

**Строка результата** над сеткой:

- слева полужирно — полная дата: «Среда, 21 октября 2026»;
- рядом вторичным цветом — относительная подпись: «через 10 дней», «завтра», «сегодня», «3 дня назад». Если у задачи уже есть дата, добавляется «· сейчас 14 окт»;
- справа моноширинным — что вставится: `SCHEDULED: <2026-10-21 Ср>` (или `DEADLINE: …`). Формат как в редакторе: день недели по настройке «Язык названий дней».

**Три месяца рядом:** предыдущий, месяц выбранной даты (по центру, название полужирным) и следующий. Когда выбор уходит в соседний месяц, вся тройка сдвигается, чтобы его месяц оказался в центре. Стрелки «‹ ›» по краям — только указатели, не кнопки.

**Сетка месяца.** Строка дней недели (Пн … Вс; первый день недели по настройке «Первый день недели»). Ячейка 30 pt высотой, скругление 7 pt.

| Состояние дня | Вид |
| --- | --- |
| Выбранный | Заливка акцентом, число полужирное цвета «на акценте» |
| Сегодня | Рамка 1.5 pt акцентного цвета, число полужирное акцентного цвета |
| Текущая дата задачи (до изменения) | Пунктирная рамка цвета дат |
| Выходные | Вторичный цвет числа |
| Есть записи на дату (агенда) | Точка 4 pt под числом: серая; если среди них дедлайн — цвет TODO |
| Дни других месяцев | Не показываются (пустые ячейки) |

**Легенда** под месяцами одной строкой: «сегодня», «текущая дата задачи», «есть записи», «дедлайн».

**Точки записей** берутся из того же индекса, что агенда. Для дат за пределами индекса точек нет. Считать индекс заново ради календаря не нужно.

## 3. Клавиатура

Фокус остаётся в поле ввода.

| Клавиша | Действие |
| --- | --- |
| ⇧← / ⇧→ | на день назад / вперёд |
| ⇧↑ / ⇧↓ | на неделю назад / вперёд |
| ⌥⇧← / ⌥⇧→ | на месяц назад / вперёд (тот же день, или последний день, если такого нет) |
| ⌥⇧↑ / ⌥⇧↓ | на год назад / вперёд |
| `.` (при пустом поле) | сегодня |
| ↩ | поставить выбранную дату и закрыть палитру |
| ⌫ (при пустом поле) | назад к шагу вариантов |
| ⎋ | закрыть палитру без изменений |

Это повторяет `org-read-date`: S-стрелки для дня и недели, M-S-стрелки для месяца и года.

**Ввод текста** в поле работает как раньше (`parseDate`: «пт», «14 окт», «+3д», «+10»). При каждом изменении текста, если он распознаётся как дата, выбор в календаре прыгает на неё. Если не распознаётся, выбор остаётся, а строка результата пишет «Не похоже на дату» вторичным цветом. ↩ ставит выбранную в календаре дату. ⇧ + стрелки после ввода двигают выбор от распознанной даты, текст в поле при этом очищается.

**Мышь** тоже работает: клик по дню выбирает его, двойной клик — выбирает и ставит. Колесо или жест листает тройку месяцев. Наведение на день не меняет выбор.

## 4. Где ещё используется

Тот же календарь открывается:

- из «Поставить дедлайн…» — метка «Дедлайн», в строке результата `DEADLINE: …`;
- из пункта «Выбрать дату…» в окне «Отложить» разбора Inbox (ТЗ 18), с `SCHEDULED`;
- из клика по плашке даты в оформленном тексте (ТЗ 19) — тип даты берётся из плашки.

Время и повтор в этом календаре не задаются. Они сохраняются, если были у текущей даты (`<2026-10-14 Ср 10:00 +1w>` → `<2026-10-21 Ср 10:00 +1w>`). Задать их можно через текстовый ввод (если `parseDate` это поддерживает) или в пикере «Выбор даты в тексте».

## 5. Разное

- **Узкое окно.** Если по ширине не помещаются три месяца (меньше ~720 pt), месяцы переносятся: сначала центральный, под ним соседние, или показывается только центральный — по реализации, главное без горизонтальной прокрутки.
- **Доступность.** Каждый месяц — роль «сетка» с названием «Октябрь 2026», день — «ячейка» с полной датой, у выбранного `aria-selected`. Изменение выбора озвучивается строкой результата.
- **Цвета** только из токенов; контраст числа на заливке не ниже 4.5:1 в обеих темах.

## Открытые вопросы и приёмка

**Открытые вопросы**

- РЕШЕНО: месяц и год — ⌥⇧ + стрелки, как M-S-стрелки в Emacs.

**Приёмка**

- В «Запланировать…» и «Поставить дедлайн…» есть пункт «Выбрать дату…» с подсказкой и клавишей; ↩ открывает календарь.
- ⇧ + стрелка на шаге вариантов сразу открывает календарь со сдвигом от исходной даты.
- В календаре три месяца, выбранный — в центре; ⇧←→ / ⇧↑↓ / ⌥⇧←→ / ⌥⇧↑↓ двигают выбор на день / неделю / месяц / год, тройка месяцев сдвигается вместе с выбором.
- Сегодня, текущая дата задачи, выходные и точки записей отмечены как в разделе 2.
- Текст в поле переводит выбор на распознанную дату; ↩ ставит дату и закрывает палитру; ⌫ на пустом поле возвращает к вариантам; ⎋ ничего не меняет.
- Время и повтор существующей даты сохраняются при смене дня.
- Тот же календарь открывается из разбора Inbox и из плашки даты в оформленном тексте.
- Светлая и тёмная темы выглядят как на макете.

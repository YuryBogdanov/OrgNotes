# ТЗ: экран «Настройки → Статусы»

2026-10-10 · Yury Bogdanov

## Цель и эталон

Нужно довести экран «Настройки → Статусы» до макета: в первой версии не работает принцип, ради которого экран рисовался, — название статуса считается из ключевого слова, а править можно только колонку «В ФАЙЛЕ».

Эталон — холст дизайна: артборды «Настройки — статусы» (в том числе пикер цвета, открытый на IN PROGRESS) и «Настройки — статусы: добавление» (состояние после «+ Состояние»). Оба артборда должны быть в светлой и тёмной теме. Названия наборов и значения цветов в макете примерные; логика важнее пикселей, но размеры, отступы и состояния из макета нужно соблюдать.

## Таблица статусов: что исправить

| № | Элемент | Сейчас | Должно быть |
| --- | --- | --- | --- |
| 1 | Колонка «Название» | Редактируемое поле с рамкой | Только чтение: текст без рамки, моно-шрифт, заглавными. Значение считается из ключевого слова (дефис → пробел: IN-PROGRESS → IN PROGRESS). В шапке колонки значок замка. Колонка не получает фокус, Tab её пропускает |

| 3 | Колонка «Цвет» | Системное выпадающее меню с названиями строчными («синий») | Цветной образец-кнопка, по клику открывает поповер-пикер (отдельный раздел ниже). Названия цветов — в пикере, с заглавной буквы |

| 10 | Кнопка «+ Завершающее» | Есть, в макете нет | Оставить: добавляет строку в конец закрытого блока, поведение то же, что у «+ Состояние» |

## Пикер цвета

Открывается кликом по цветному образцу (кружок 12–14 pt) в колонке «Цвет», а также с клавиатуры (Space или Return на образце). Это поповер с выносной стрелкой, ширина 268 pt.

Состав сверху вниз:

- Заголовок «Цвет статуса», справа название текущего цвета.
- Сетка 4×2 из восьми цветов: кружок 28 pt, под ним подпись 11 pt. У выбранного акцентное кольцо и белая галочка внутри.
- Блок «Так будет выглядеть»: две плашки, светлая (#fff) и тёмная (#1e1e22), на каждой чип статуса с его ключевым словом цветом для этой темы.
- Кнопка «Другой цвет…» открывает системную панель цветов macOS (NSColorPanel).
- Пояснение: «Цвета подбираются отдельно для светлой и тёмной темы».

Выбор применяется сразу, поповер остаётся открытым, чтобы было видно превью. Закрывается по Esc, клику вне поповера или повторному клику по образцу.

Палитра. Каждому цвету соответствуют две величины, тема выбирает свою:

| Цвет | Светлая тема | Тёмная тема |
| --- | --- | --- |
| Серый | #5f5f66 | #a9a9b3 |
| Красный | #c4262e | #ff7b80 |
| Оранжевый | #935300 | #f0b04d |
| Зелёный | #1d7f3a | #6fd58a |
| Бирюзовый | #0b7a6f | #5fd3c2 |
| Синий | #0a58c2 | #6cb4ff |
| Фиолетовый | #7a3fc4 | #c39bff |
| Розовый | #a3187a | #f58ad4 |

Произвольный цвет хранится как hex для светлой темы, тёмный вариант считается автоматически: яркость поднимается, пока контраст к #1e1e22 не достигнет 4.5:1. Выбранный произвольный цвет показывается девятым образцом в сетке с галочкой.

Клавиатура: стрелки двигаются по сетке, Return выбирает, Esc закрывает. Для VoiceOver у каждого образца подпись с названием цвета.

Цвет используется везде, где показан статус: чипы в редакторе, навигаторе и агенде, цепочка «Как это выглядит». Чип — текст этим цветом на фоне того же цвета с прозрачностью около 12–15%; контраст текста не ниже 4.5:1 в обеих темах.

## Кнопка «+ Состояние»

После нажатия курсор сразу стоит в поле «В ФАЙЛЕ» новой строки, без дополнительного клика. Остальное поведение:

1. Строка добавляется в открытый блок, перед разделителем закрытых состояний. «+ Завершающее» добавляет строку в конец закрытого блока.
2. Начальные значения: цвет серый, название «—», клавиша пустая.
3. Поле «В ФАЙЛЕ» в фокусе: акцентное кольцо, плейсхолдер «например, REVIEW». Таблица прокручивается так, чтобы строка была видна.
4. Пока пользователь печатает, ввод приводится к верхнему регистру, пробел заменяется на дефис, а «Название» и «Клавиша» обновляются на лету. Рядом с полем подсказка: «Введите ключевое слово и нажмите ↩ · ⎋ — отмена».
5. Return подтверждает строку: фокус снимается, обновляются цепочка «Как это выглядит» и строка `#+TODO:`. Esc удаляет строку. Потеря фокуса с пустым полем тоже удаляет строку, с корректным значением — подтверждает.
6. Некорректное значение Return не подтверждает: поле краснеет, под ним причина (см. следующий раздел).
7. Повторное нажатие кнопки при уже открытой пустой строке возвращает фокус в неё, вторую строку не создаём.

Редактирование существующего статуса: клик по полю «В ФАЙЛЕ» ставит курсор туда же, правила ввода те же.

## Валидация и граничные случаи

Ключевое слово: заглавные буквы, цифры, дефис и подчёркивание, до 24 символов. Запрещены символы, которые Org Mode использует в синтаксисе `#+TODO:`: круглые скобки, вертикальная черта, @, !, /. Пробел автоматически становится дефисом. Пустое слово недопустимо.

Уникальность: слово не должно повторяться ни в своём наборе, ни в других наборах проекта, иначе непонятно, какой набор применять к заголовку. Ошибка: «Такое слово уже есть в наборе «Задачи»».

Минимумы: в наборе остаётся хотя бы одно открытое состояние, последнее удалить нельзя; единственный набор тоже нельзя удалить. Если удалили статус, выбранный как «Состояние новой задачи», подставляется первый открытый.

Удаление статуса. Если слово не встречается в заголовках, удаляем сразу. Если встречается, показываем подтверждение: «NEXT используется в 7 заголовках. Файлы не изменятся: слово останется в тексте, но перестанет считаться статусом». Кнопки «Удалить» и «Отмена». Так счётчик, убранный из поля «В ФАЙЛЕ», остаётся доступен там, где он нужен.

Переименование статуса, который используется (предложение): диалог «Заменить NEXT на REVIEW в 7 заголовках?» с кнопками «Заменить в файлах», «Только в настройках», «Отмена». Если это слишком объёмно для первой итерации, достаточно предупреждения без замены.

Перетаскивание строк: линия вставки акцентным цветом; перенос между открытым и закрытым блоком меняет тип состояния.

Изменения применяются сразу, кнопки «Применить» нет.

## Остальные расхождения

- Вкладки. В реализации пять: нет «Календарь». Порядок по макету: Основные, Статусы, Теги, Агенды, Календарь, Файлы.
- Окно. Настройки открыты листом поверх главного окна с затемнением. В макете это отдельное окно (⌘,), не модальное: главное окно остаётся доступным.
- Порядок наборов. Стрелки ↑↓ в шапке редактора набора заменить перетаскиванием в левом списке. Правило «первый набор используется по умолчанию» и подсказка про ^⇧← и ^⇧→ остаются.
- Состав наборов. В реализации: Задачи — NEXT, TODO, WAIT, DONE, CANCELLED; Встречи — MEETING, FINISHED, SKIPPED; Цели на квартал — BACKLOG, ACTIVE, STATE, COMPLETED. Если это тестовые данные, оставить; для набора по умолчанию использовать состав из макета: Задачи — NEW, TODO, IN PROGRESS, BLOCKED, DONE; Встречи — MEETING, FINISHED, CANCELLED; Цели на квартал — BACKLOG, ACTIVE, COMPLETED. Слово STATE в целях похоже на ошибку, проверить.
- Тулбар главного окна (виден на заднем плане, к настройкам не относится, но в бэклог). Утверждённый вариант: без кнопки «Заметки», поиск перенесён в навигатор, вместо текстовых «Агенда» и «Календарь» три иконки — «Второй редактор», «Агенда», «Календарь». Дата в хлебных крошках обрезается («Сб, 10 октября 202»).

## Критерии приёмки

- [ ] Скриншоты экрана в светлой и тёмной теме сопоставлены с артбордами: порядок колонок, размеры, отступы, шрифты совпадают.
- [ ] Колонка «Название» только для чтения, не получает фокус, Tab её пропускает.
- [ ] Клик по «В ФАЙЛЕ» ставит курсор в поле; Return сохраняет, Esc отменяет правку.
- [ ] «+ Состояние» создаёт серую строку, курсор сразу в её поле «В ФАЙЛЕ», без дополнительного клика.
- [ ] Пикер цвета: восемь именованных цветов, галочка на выбранном, превью на светлой и тёмной плашках, «Другой цвет…» открывает системную панель.
- [ ] Цвета в тёмной теме берутся из тёмной колонки палитры, контраст чипов не ниже 4.5:1.
- [ ] Строка `#+TODO:` и цепочка «Как это выглядит» пересчитываются при любом изменении набора.
- [ ] Заголовки колонок выровнены по сетке при ширине окна от 900 до 1400 pt.
- [ ] В строках нет кнопок ↑↓; перетаскивание и ⌥↑/⌥↓ работают.
- [ ] Валидация, подтверждения удаления и сообщения об ошибках соответствуют разделу про граничные случаи.
- [ ] Весь экран доступен с клавиатуры и через VoiceOver.
- [ ] Добавлена вкладка «Календарь», настройки открываются отдельным окном по ⌘,.

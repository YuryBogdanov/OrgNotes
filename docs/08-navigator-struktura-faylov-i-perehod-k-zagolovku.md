# ТЗ: навигатор, структура файла и переход к заголовку

2026-10-10 · Yury Bogdanov

## Контекст

Навигатор должен показывать только папки и файлы, а структура файла — жить в другом месте. Сейчас шеврон стоит и у папок, и у файлов с заголовками, поэтому нельзя быстро найти файл глазом: файл теперь не отличается по отсутствию шеврона, а левый край названий рвётся.

Блок состоит из трёх частей, которые делаются вместе, потому что заменяют друг друга: шеврон только у папок в навигаторе (правка 1), панель «Структура» в инспекторе (правка 2) и переход к заголовку в командной палитре по «#» (правка 3). После правки 2 и 3 показывать заголовки в навигаторе больше не нужно, поэтому они по умолчанию выключены.

Работа над этим блоком опирается на макеты «Навигатор — шеврон только у папок», «Навигатор — заголовки включены», «Инспектор — панель Структура» и «Палитра — переход к заголовку (#)» в разделе «Навигатор и структура файла» на дизайн-канве.

## 1. Навигатор: шеврон только у папок

**Резервная колонка.** Слева от иконки каждой строки навигатора резервируется колонка шириной 10 pt под шеврон. Иконки и названия всех строк одного уровня выровнены по одной вертикали независимо от того, нарисован шеврон или нет. Глубина вложенности добавляет отступ 14 pt на уровень.

**Папки.** Шеврон ▸/▾ показывается у каждой папки, у которой есть содержимое. Пустая папка шеврона не имеет. Клик по шеврону или по строке папки раскрывает и сворачивает её; ←/→ работают как в Finder.

**Файлы.** Шеврона у файлов нет, поэтому файл визуально отличается от папки: глаз перебирает строки без шеврона и находит файл, как в любой IDE.

**Настройка «Показывать заголовки в навигаторе».** Раздел настроек «Навигатор». По умолчанию выключена (это предположение, см. открытые вопросы). Выключена: заголовки в навигаторе не показываются, у файлов нет шеврона. Включена: у файла с заголовками шеврон появляется только когда файл раскрыт или на него наведён курсор; у раскрытого файла шеврон остаётся, у остальных скрыт (opacity 0, место в колонке сохраняется, строка не прыгает).

**Строки заголовков** (при включённой настройке): отступ на один уровень глубже файла, ключевое слово TODO/DONE/NEXT/WAIT показывается значком. Клик по заголовку открывает файл (если не открыт) и ставит курсор на этот заголовок.

**Макеты:** «Навигатор — шеврон только у папок» (настройка выключена), «Навигатор — заголовки включены» (наведён journal, виден шеврон).

## 2. Панель «Структура» в инспекторе

**Переключатель.** В верхней части инспектора — два значка-вкладки: «Задача» (текущее содержимое инспектора) и «Структура». Выбор запоминается для окна. Содержимое вкладки «Задача» не меняется.

**Заголовок панели:** «СТРУКТУРА · имя файла» (без расширения). Показывает структуру файла активного редактора; при переключении вкладки или панели редактора обновляется.

**Фильтр.** Поле поиска по тексту заголовков; при вводе дерево показывает совпадения вместе с родителями, совпавший фрагмент подсвечивается.

**Режим «Все / Только задачи».** Сегментированный переключатель. «Только задачи» оставляет заголовки с ключевым словом (TODO, NEXT, WAIT, DONE и т. п. из настроек статусов) и их родителей.

**Дерево.** Заголовки с отступом по уровню (14 pt на уровень), шеврон у заголовков с подзаголовками, клик по шеврону сворачивает ветку. У заголовка: ключевое слово значком, текст, у свёрнутой ветки — счётчик вложенных задач (например, 1/3 — выполнено из всего).

**Текущий заголовок** (тот, в котором стоит курсор) подсвечивается и держится в зоне видимости; при движении курсора по файлу подсветка перемещается.

**Переход.** Клик или Return по строке ставит курсор на заголовок в активном редакторе и прокручивает его в видимую область. Фокус при этом остаётся в списке, если переход сделан клавишей ↑/↓ (предпросмотр), и уходит в редактор по Return или двойному клику.

**Пустое состояние.** В файле нет заголовков — «В файле нет заголовков». Нет совпадений по фильтру — «Ничего не найдено». Не открыт ни один файл — «Откройте файл, чтобы увидеть структуру».

**Макет:** «Инспектор — панель Структура».

## 3. Командная палитра: режим «#»

**Вход.** Символ «#» первым в строке палитры включает режим перехода к заголовку. Режим виден по префиксу «#» в поле и плейсхолдеру «заголовок». Символ «@» в палитре не занят этим режимом и зарезервирован под упоминания людей.

**«№» равнозначно «#».** На русской раскладке Shift+3 даёт «№», поэтому «№» первым символом запроса включает тот же режим, что и «#». Это задуманное поведение, не баг. Распознавать нужно по физической клавише Shift+3, а не по самому символу; после ввода в поле показывается «#». Вынесение в настройки — в позднейших версиях.

**Список.** Плоский список заголовков текущего файла (файл активного редактора) в порядке следования в файле. Отступ строки — 10 pt + 18 pt на уровень заголовка. В строке: значок заголовка, текст, справа ключевое слово (TODO/DONE/NEXT/WAIT), если оно есть.

**Поиск.** Ввод после «#» фильтрует список по тексту заголовка (нечёткое совпадение, как в остальных режимах палитры); совпавшие символы выделяются.

**Действия.** ↑/↓ — выбор, Return — перейти к заголовку: палитра закрывается, курсор ставится на заголовок, он прокручивается в видимую область. Esc закрывает палитру. Стирание «#» возвращает общий режим.

**Подсказка в контекстной палитре.** В режиме по умолчанию есть строка «Переход к заголовку в текущем файле. Для другого файла уберите «#»».

**Нет файла.** Если ни один файл не открыт, режим показывает «Откройте файл, чтобы перейти к заголовку».

**Макет:** «Палитра — переход к заголовку (#)».

## Открытые вопросы и приёмка

**Открытые вопросы**

- Заголовки в навигаторе по умолчанию скрыты — это предположение дизайна, владелец продукта его ещё не подтвердил. Если оставим показ включённым, дефолт в разделе 1 меняется, остальное — нет.
- Расположение настройки «Показывать заголовки в навигаторе» в экране настроек не нарисовано — нужен макет либо решение разработчика в духе стандартного переключателя.
- Горячая клавиша открытия вкладки «Структура» не назначена; предлагается команда в палитре «Показать структуру файла» без отдельного сочетания клавиш.
- Поведение на очень больших файлах (тысячи заголовков): виртуализация списка — на усмотрение разработчика.

**Приёмка**

- Иконки и названия всех строк навигатора одного уровня выровнены, независимо от наличия шеврона.
- Шеврон есть только у непустых папок; у файлов — только при включённой настройке и только у раскрытого или под курсором.
- При выключенной настройке заголовки в навигаторе не появляются ни при каких действиях.
- Панель «Структура» показывает файл активного редактора и обновляется при смене вкладки/панели и при правке заголовков.
- Фильтр и «Только задачи» работают вместе, родители совпавших заголовков сохраняются.
- Клик по строке в «Структуре» и Return в палитре «#» ставят курсор на нужный заголовок и прокручивают его в видимую область.
- «@» в палитре не переключает никакой режим.
- Тёмная и светлая темы оформлены токенами темы, без жёстко зашитых цветов.

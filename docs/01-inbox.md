# ТЗ: Inbox — раздел навигатора и быстрый ввод задачи (⇧⌘I)

2026-10-12 · Yury Bogdanov

Inbox — это один выбранный .org-файл (обычно `inbox.org`), куда быстро кладутся задачи, чтобы потом разобрать их по файлам. Добавляем в навигатор раздел Inbox со списком задач и действиями разбора, а также окно быстрого ввода по ⇧⌘I, которое работает из любой программы. Три способа создать задачу: написать заголовок прямо в файле, кнопка «+ Задача» в навигаторе, хоткей ⇧⌘I.

**Решения, принятые с заказчиком.** Раздел показывает список и предлагает действия разбора (открыть, перенести, дата, готово, удалить). Запись в файл — `* TODO Заголовок` со свойством `:CREATED:`. Хоткей ⇧⌘I глобальный.

Макеты (раздел доски «Inbox: раздел навигатора, быстрая задача (⇧⌘I), перенос», каждый в светлой и тёмной теме): «Inbox — список и разбор», «Inbox — не настроен», «Новая задача — заголовок», «Новая задача — детали», «Inbox — перенести: 1. файл», «Inbox — перенести: 2. заголовок».

## 1. Панель разделов навигатора

**Порядок кнопок.** В полосе разделов вверху навигатора слева направо: «Файлы» (бывшие «Заметки»), «Inbox», «Задачи», «Агенда», «Теги», «Поиск». «Файлы» — первый и основной раздел, он открывается по умолчанию. Работают сейчас «Файлы», «Inbox» и «Агенда»; остальные кнопки остаются на месте и пока неактивны.

**Подсказки.** У каждой кнопки есть подсказка с названием («Файлы», «Inbox»). Выбранный раздел подсвечен цветом акцента и фоном выбранного элемента. Порядок меняется во всех местах, где нарисована эта полоса (основное окно, два редактора, режим «Агенда»).

**Счётчик.** На кнопке Inbox показывается число неразобранных задач маленьким бейджем (предложение, не нарисовано; см. открытые вопросы).

## 2. Файл Inbox и заглушка

**Что такое файл Inbox.** Любой .org-файл рабочей папки, выбранный пользователем. По умолчанию приложение предлагает `inbox.org`, если такой файл есть в корне рабочей папки, но само не подбирает файл без подтверждения. Настройка хранится для каждой рабочей папки (путь от корня).

**Заглушка, пока файл не выбран.** В разделе «Inbox» посередине — иконка ящика, заголовок «Inbox пока не настроен», описание «Выберите файл, в который будут попадать быстрые задачи», главная кнопка «Выбрать файл…» и текстовая кнопка «Создать inbox.org в рабочей папке». «Выбрать файл…» открывает палитру выбора файла с фильтром (как в меню jump bar); «Создать inbox.org» создаёт пустой файл в корне и сразу назначает его. Та же заглушка показывается, если выбранный файл удалён или переименован без видимого приложению изменения, с дополнительной строкой «Файл inbox.org не найден».

**Смена файла.** В настройках (раздел «Inbox», не нарисован) файл можно изменить. Старый файл не трогаем, задачи в нём не переносятся.

## 3. Список Inbox и действия

Панель показывает все заголовки верхнего уровня файла Inbox с незавершённым статусом (TODO и другие). Порядок: сверху новые (по `:CREATED:`), задачи без `:CREATED:` в конце в порядке файла.

Строка: чекбокс статуса, заголовок в одну строку (с обрезкой), справа относительное время создания («5 мин», «вчера»). Если есть детали, под заголовком первая строка деталей серым шрифтом. Выбранная строка подсвечивается акцентом, навигация стрелками ↑/↓.

Действия по задаче (кнопки появляются справа при наведении и для выбранной строки, а также в контекстном меню):

- **Открыть** (↩ или двойной клик) — открывает Inbox-файл в редакторе на этом заголовке.
- **Перенести** — открывает палитру выбора места назначения (раздел 6).
- **Дата** — небольшой поповер: переключатель `SCHEDULED` / `DEADLINE`, быстрые варианты «Сегодня», «Завтра», «На неделе», календарь. Задача остаётся в Inbox, но получает дату.
- **Готово** — статус DONE, ставится `CLOSED:`, строка исчезает из списка с короткой анимацией. Отмена через ⌘Z в течение сессии.
- **Удалить** — удаляет заголовок вместе с содержимым из файла; запрашивает подтверждение, если у задачи есть детали.

Все действия пишут прямо в файл Inbox теми же механизмами, что и обычный редактор (в том числе с учётом конфликтов с диском).

## 4. Быстрый ввод задачи

**Вызов.** Глобальный хоткей ⇧⌘I работает из любой программы (требуется регистрация системного хоткея; приложение должно быть запущено, при закрытом окне оно остаётся в меню-баре/Dock). Кнопка «+» в панели Inbox открывает тот же интерфейс внутри окна. Хоткей меняется в настройках; при конфликте с другим приложением показываем предупреждение.

**Интерфейс.** Окно по типу палитры команд: по центру экрана, без заголовка, поверх остальных окон, закрывается по Esc или потере фокуса. Если вызвано из другой программы — появляется отдельной панелью, главное окно не выводится вперёд.

**Поля.**

- Заголовок — обязательное, основной шрифт, фокус при открытии.
- Детали — необязательное, ниже заголовка, шрифт чуть меньше, многострочное; поле появляется после Tab (до этого показана подсказка «Tab — детали»).

**Клавиши.**

- В заголовке: Enter — создать задачу; Tab — перейти в детали. Пустой заголовок — Enter ничего не делает, поле слегка подсвечивается.
- В деталях: Enter — новая строка; ⌘↩ — создать задачу; ⇧Tab — вернуться к заголовку.
- ⌘↩ создаёт задачу и из заголовка.
- Esc — закрыть без сохранения; если что-то введено, окно закрывается сразу, но черновик хранится до следующего вызова.

**После создания.** Окно закрывается, на 1–2 секунды появляется ненавязчивое подтверждение «Добавлено в Inbox»; счётчик в панели обновляется. Если Inbox-файл не настроен — вместо ввода показывается заглушка с выбором файла, введённый текст не теряется.

## 5. Запись в файл

Новая задача добавляется в конец Inbox-файла (отделяется пустой строкой не нужно). Формат:

```
* TODO Заголовок
:PROPERTIES:
:CREATED: [2026-10-11 Sun 14:32]
:END:
Детали, если были введены, как обычный текст под заголовком
```

Правила: заголовок очищается от переносов строк и лишних пробелов; строки деталей, начинающиеся с `*` и пробела, экранируются (перед ними ставится `,`), чтобы не превратиться в заголовки. Если файл не оставляет переноса в конце, добавляем его. Запись всегда идёт сразу на диск. Если Inbox-файл открыт в редакторе с несохранёнными правками, сначала сохраняем их, потом добавляем задачу, и редактор подхватывает изменение с диска без диалога конфликта. Дата создания — локальное время пользователя.

Задачи, написанные в файл вручную (в том числе в Emacs или через синхронизацию), появляются в панели после обновления файла (наблюдение за файлом, без перезапуска). Заголовки без `:CREATED:` тоже показываются.

## 6. Перенос задачи

«Перенести» запускает общий сценарий переноса из ТЗ «перенос заголовка в другой файл (файл → заголовок)», № 16. Там описано всё: шаги, клавиши, вставка, атомарность, тост. Кратко:

- Шаг 1 — выбор файла: плоский список «Недавние» и «Все файлы» с путём в подсказке, поиск по имени и пути. Inbox-файла в списке нет. Вход в папки по →/← убран.
- Шаг 2 — выбор места: закреплённая строка «Перенести на 1-й уровень» (выбрана по умолчанию, ⌘↩; раньше она называлась «В конец файла») и дерево заголовков файла. ↩ вставляет задачу последним ребёнком выбранного заголовка.

Задача вырезается из Inbox вместе со свойствами и деталями, `:CREATED:` сохраняется, уровень звёздочек пересчитывается. Сначала идёт запись в целевой файл, и только потом удаление из Inbox. После переноса — тост «Перенесено в <файл> › <заголовок>» с кнопками «Открыть» и «Отменить». Задача исчезает из списка, выбор переходит на следующую.

Отличия от сценария в палитре: плашка «Переносится задача · из inbox», ⌫ на шаге 1 ничего не делает.

## 7. Настройки Inbox

В окне настроек новая вкладка «Inbox» (между «Календарь» и «Файлы»). Строка «Файл для быстрых записей» из вкладки «Файлы» удалена, она заменена этой вкладкой.

- **Файл**: файл Inbox (кнопка «Выбрать…»), куда добавлять (в конец файла).
- **Быстрый ввод**: сочетание клавиш (по умолчанию ⇧⌘I), переключатель «Работает из любой программы», подтверждение «Добавлено», статус новой задачи, запись `:CREATED:`.
- **Список**: порядок, счётчик на кнопке, показ деталей под заголовком.

Если файл не выбран, поля «Быстрый ввод» остаются доступными, но хоткей открывает заглушку с выбором файла.

## Открытые вопросы и приёмка

**Открытые вопросы.**

- РЕШЕНО: счётчик нужен (бейдж на кнопке Inbox, число задач в списке; 0 — бейдж скрыт; больше 99 — «99+»). Отключается в настройках.
- РЕШЕНО: пока без горячих клавиш для действий над строкой, вернёмся после опыта использования.
- РЕШЕНО: запись всегда сразу на диск.
- РЕШЕНО: настройки Inbox нарисованы (доска «Настройки — Inbox»), см. раздел 7.

**Приёмка.**

- Во всех полосах навигатора «Файлы» стоит первым, дальше Inbox.
- Без настроенного файла показывается заглушка; после выбора — список.
- Задачу можно создать тремя способами: записью в файл, кнопкой, ⇧⌘I из любой программы.
- Enter создаёт задачу только с заголовком; Tab открывает детали, там Enter — новая строка, ⌘↩ — создать.
- Формат записи совпадает с разделом 5, файл в редакторе сразу показывает новую задачу.
- Действия открыть / перенести / дата / готово / удалить работают без потери данных при ошибках записи.

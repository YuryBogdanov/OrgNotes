# ТЗ: поиск в файле (⌘F) и по всем файлам (⇧⌘F)

2026-10-11 · Yury Bogdanov

## Контекст

Поиска в приложении пока нет никакого. В навигаторе заготовлена неактивная кнопка «Поиск». Делаем две вещи:

1. **Поиск в текущем файле** — ⌘F, полоса поиска в редакторе, подсветка совпадений, переход по ним.
2. **Поиск по всем файлам** — ⇧⌘F, раздел «Поиск» в навигаторе. Запрос запускается по ↩, результаты сгруппированы по файлам.

Замена текста («Найти и заменить») в эту задачу не входит, решим по опыту использования.

Макеты: группа «Поиск: в файле и по всем файлам», в светлой и тёмной теме.

- «Поиск в файле (⌘F)»;
- «Глобальный поиск (⇧⌘F) — результаты»;
- «Глобальный поиск — пустой запрос».

## 1. Поиск в файле

### 1.1. Вызов и закрытие

- ⌘F и пункт меню «Правка → Найти → Найти…» открывают полосу поиска в **активной панели** редактора. Фокус переходит в поле. Если в тексте было выделение в пределах одной строки, оно подставляется в поле. Иначе подставляется последний запрос этой панели, выделенный целиком, чтобы его можно было сразу перепечатать.
- Повторный ⌘F при открытой полосе переводит фокус в поле и выделяет запрос.
- **Закрытие:** ⎋ в поле или кнопка «Готово ⎋». Подсветка снимается. Курсор остаётся на текущем совпадении, фокус возвращается в текст.
- Полоса привязана к панели. При переключении вкладок в этой панели она остаётся открытой, а поиск пересчитывается для нового файла. Во второй панели полоса своя.

### 1.2. Полоса поиска

Под строкой пути с переключателем «Текст / Оформление», над текстом. Высота ~40 pt, фон панели, нижняя граница. Слева направо:

- **Поле** шириной до 320 pt (минимум 200) с иконкой лупы и акцентной рамкой в фокусе. Справа внутри поля счётчик «2 из 6». Пока ничего не найдено — «Не найдено» цветом TODO, рамка поля тоже цветом TODO. При пустом поле счётчика нет.
- **Кнопки** «Предыдущее» и «Следующее», парные, со стрелками вверх и вниз. Сочетания в подсказке.
- **Переключатели** «Aa» (учитывать регистр) и «Слово» (слово целиком). Включённый — акцентный фон. Состояние запоминается на устройстве.
- **Пометка**:
  - «и N в свёрнутых заголовках», если часть совпадений скрыта свёрткой;
  - «из глобального поиска», если запрос пришёл из раздела 2.
- **Справа** кнопка «Готово ⎋».

На узкой панели элементы переносятся на вторую строку, поле не сжимается меньше 200 pt.

### 1.3. Поиск и подсветка

- Ищет **по мере ввода**, с задержкой ~100 мс. Первым текущим становится совпадение, ближайшее к курсору вниз по тексту (с переходом в начало файла).
- **Без учёта регистра по умолчанию**; «ё» и «е» считаются равными (как в палитре). «Слово» — совпадение только на границах слов.
- **Ищем по реальному тексту файла**, со звёздочками и разметкой. В режиме «Оформление» (ТЗ 19) совпадение внутри заменённого элемента раскрывает его строку.
- **Подсветка:** все совпадения — мягкий жёлтый фон (токен `hl`); текущее — насыщенный жёлтый (`hlCur`) с обводкой и тёмным текстом (`hlCurFg`), в обеих темах. Совпадения подсвечиваются и в линейке прокрутки справа: жёлтые засечки.
- **Свёрнутые заголовки и drawers:** совпадения внутри тоже считаются. На строке свёрнутого заголовка плашка «N в свёрнутом» на фоне `hl`. При переходе к такому совпадению заголовок (или drawer, ТЗ 17) разворачивается.
- **Текст меняется** во время поиска (набор, внешнее изменение): совпадения пересчитываются; текущим остаётся ближайшее к прежней позиции.
- **Большие файлы:** подсветка строится для видимой области, счётчик считается по всему файлу. До 50 000 строк — без заметной задержки.

### 1.4. Клавиши

| Клавиша | Где | Действие |
| --- | --- | --- |
| ⌘F | везде в окне | открыть полосу / фокус в поле |
| ↩ / ⇧↩ | в поле | следующее / предыдущее |
| ⌘G / ⇧⌘G | в поле и в тексте | следующее / предыдущее (работают и при закрытой полосе, по последнему запросу) |
| ⌘E | в тексте | взять выделение как запрос (как в macOS) |
| ⎋ | в поле | закрыть полосу |

Переход прокручивает текст так, чтобы совпадение было примерно в верхней трети панели, и ставит на него выделение. На последнем совпадении ↩ переходит к первому и коротко показывает в счётчике «с начала».

## 2. Поиск по всем файлам

### 2.1. Вызов

- ⇧⌘F, пункт меню «Правка → Найти → Найти во всех файлах…» и кнопка «Поиск» в полосе навигатора (она становится активной). Сочетание ⌃⌘6 — по аналогии с ⌃⌘1/2/3 у других разделов. Если навигатор скрыт, он показывается.
- Фокус в поле. Если в редакторе есть выделение в пределах строки, оно подставляется в поле, но поиск не запускается до ↩.
- Раздел помнит последний запрос и результаты до перезапуска приложения. При возвращении в раздел они на месте.

### 2.2. Поле и параметры

- **Поле** во всю ширину навигатора, с лупой. Пока запрос не запущен, внутри справа подсказка «↩ искать». Когда в поле есть текст — кнопка очистки ×.
- **Поиск запускается по ↩**, не по мере ввода. После изменения запроса старые результаты остаются видны, пока не нажат ↩.
- **Под полем:**
  - сегменты «Везде / Заголовки / Текст»: где искать — во всём тексте, только в строках заголовков (текст заголовка, статус и теги) или только в тексте под заголовками;
  - переключатели «Aa» и «Слово» — общие с поиском в файле.
- **Что ищем:** все `.org`-файлы рабочей папки, кроме служебной `.orgnotes`. Для открытых файлов берётся текст из редактора, включая несохранённые правки, для остальных — с диска.

### 2.3. Результаты

- **Сводка:** «14 совпадений в 4 файлах», справа кнопка «Свернуть все» / «Развернуть все». Пока идёт поиск — «Ищу… N файлов» с индикатором, результаты появляются по мере нахождения.
- **Группа файла:** стрелка свёртки, иконка, имя без расширения, путь относительно рабочей папки вторичным цветом (для корня — «корень»), справа счётчик совпадений в файле.
  - Порядок групп: сначала открытые файлы, потом по числу совпадений, потом по имени.
  - По умолчанию развёрнуты первые 5 групп.
- **Результат:**
  - первая строка, мелко и вторичным цветом: путь заголовка, в котором лежит совпадение («Q4 2026 › Подготовить бюджет 2027»), справа «стр. N»;
  - вторая строка: фрагмент строки с подсвеченным совпадением (фон `hl`), до ~80 символов вокруг, с многоточиями;
  - если совпала строка заголовка — слева иконка заголовка, статус цветом, текст полужирный;
  - звёздочки и отступы во фрагменте не показываются.
- **Ограничения:** в группе показываются первые 4 совпадения, дальше строка-ссылка «Ещё N» (раскрывает группу целиком). Если совпадения лежат в одном свёрнутом подзаголовке — «Ещё N в „План найма на Q4“». Всего до 1000 совпадений, дальше сводка пишет «Показаны первые 1000» с предложением уточнить запрос.
- **Ничего не найдено:** «Ничего не найдено» и подсказка проверить «Aa», «Слово» и область поиска.

### 2.4. Переход к результату

- **Клик или ↩ на результате** открывает файл в активной панели (или переключает на уже открытую вкладку), ставит курсор на совпадение и разворачивает свёрнутое над ним.
- **В редакторе открывается полоса поиска (раздел 1)** с тем же запросом и параметрами, с пометкой «из глобального поиска». Текущим становится выбранное совпадение. Дальше ⌘G / ⇧⌘G ходят по совпадениям этого файла.
- **Выбранный результат** в списке выделен фоном выбора и акцентной обводкой.
- **Клавиатура в списке:** ↑↓ по результатам (заголовки групп пропускаются), ← / → сворачивают и разворачивают группу, ↩ открывает. Из поля ↓ переводит фокус в список.
- **⌥⌘G / ⇧⌥⌘G** — следующий / предыдущий результат глобального поиска, с переходом между файлами, даже когда фокус в тексте.

### 2.5. Пустой запрос

Пока поиск не запускался, под полем «НЕДАВНИЕ ЗАПРОСЫ»: до 8 последних глобальных запросов с относительным временем. Клик подставляет запрос и сразу ищет. История хранится на устройстве (localStorage), очищается пунктом контекстного меню «Очистить историю». Внизу подсказка: «Наберите текст и нажмите ↩ — поиск по всем файлам рабочей папки. Поиск в текущем файле — ⌘F».

### 2.6. Изменения файлов

Если файл изменился после поиска (правка, внешнее изменение, переименование), его группа помечается «изменён — ↩ обновить». Номера строк и фрагменты могут устареть. Повторный ↩ в поле обновляет все результаты. Удалённый файл пропадает из результатов.

## 3. Производительность

Глобальный поиск не блокирует интерфейс: файлы читаются и просматриваются в фоне (Rust-команда или worker), результаты приходят порциями. Цель — рабочая папка на 1000 файлов и 50 МБ отвечает за 1–2 секунды. Повторный запуск во время поиска отменяет предыдущий.

## Открытые вопросы и приёмка

**Открытые вопросы**

- ОТЛОЖЕНО: «Найти и заменить» — по опыту использования.
- Регулярные выражения в поиске — не делаем, пока не понадобятся.

**Приёмка**

- ⌘F открывает полосу в активной панели с фокусом в поле; выделение подставляется как запрос; ⎋ закрывает и снимает подсветку.
- Поиск по мере ввода, без учёта регистра, «ё» = «е»; счётчик «K из N»; ↩/⇧↩ и ⌘G/⇧⌘G ходят по кругу.
- Все совпадения подсвечены мягким жёлтым, текущее — насыщенным; засечки в линейке прокрутки.
- Совпадения в свёрнутых заголовках и drawers посчитаны, показаны плашкой и разворачиваются при переходе.
- ⇧⌘F открывает раздел «Поиск» с фокусом в поле; ↩ запускает поиск по всем файлам; результаты сгруппированы по файлам с путём заголовка, номером строки и подсвеченным фрагментом.
- «Везде / Заголовки / Текст», «Aa», «Слово» влияют на выдачу.
- Клик по результату открывает файл на совпадении, полоса поиска в редакторе уже с этим запросом.
- Недавние запросы видны при пустом поле и запускаются кликом.
- Поиск по большой папке не подвешивает интерфейс.
- Светлая и тёмная темы — как на макетах, цвета из токенов.
